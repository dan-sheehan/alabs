# Screenshots

Screenshots of the alabs application as built at commit `b06897a`, taken on
16 September 2026 with CleanShot X from the author's own alabs root, in the
dark interface at the default 1280×800 window, and scaled to 1280 pixels
wide. They show the application; they are not illustrations. The root path
in the rail footer and the where line, and the private paragraphs of one
README, are blurred. The work folders in the pictures are the author's own
projects at the time.

- `home.png` (1280×803): Home. The rail, the place list with each work
  folder's view status, and the root map with one box per work folder and
  one per knowledge folder. Nothing is selected in the inspector.
- `overview.png` (1280×799): the Overview of the work folder `defiance`:
  action row, rendered README excerpt, TOP LEVEL table, and THIS PLACE with
  kind, branch, last commit and the path of its view.
- `editor.png` (1280×804): `PLAN.md` of `defiance` open in the editor with
  the file tree beside it; the strip holds the Overview and both the
  rendered and the source tab for the file.
- `markdown.png` (1280×806): `README.md` of `cockpit-v2` rendered in the
  Markdown tab, with `Open source` in the header and the restore notice
  above it.
- `visual-view.png` (1280×806): the Visual View of `defiance` with the
  landmark `Inventory and fetch` selected and its three files listed in the
  inspector.

The README uses all five under [What it looks like](../../README.md#what-it-looks-like).
