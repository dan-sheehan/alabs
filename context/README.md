# Context

This folder shows where `alabs` looks for Context. What alabs is for: [what-is-alabs.md](../what-is-alabs.md)

Context is what you deliberately give the current work: who you are, what you are working on and what you have already decided. The Wiki holds outside knowledge that might help. Context is what you choose to supply.

## Where alabs looks

alabs reads Context from a folder named `context` directly inside the alabs root you open. It does not read this folder: this copy only shows the shape.

```text
<your alabs root>/
└── context/
    ├── about-me.md
    └── current-goals.md
```

Use ordinary Markdown or text files. Ask on the Wiki Overview reads the top-level files here together with the Wiki. The limits are in [wiki/README.md](../wiki/README.md).
